# Vastra Saarthi

*Vastra Saarthi* is a web-based campus laundry management system designed
to replace manual register-based tracking with a *digital, efficient, and
transparent solution*. In many colleges, laundry records are maintained
manually, leading to errors, lack of visibility, and inconvenience for
students unaware of when their laundry is ready.

## About the Project

This project provides a *centralized platform* where laundry workers can
update laundry entries and manage status across the entire workflow:
*Submitted* --> *Ready* --> *Collected*. Students can *track their
laundry in real-time* and receive notifications when it is ready for
collection.

## Technology

Built using *React, **Axios, and *modern routing techniques, Vastra
Saarthi improves operational efficiency, reduces unnecessary visits, and
enhances the overall user experience by bringing *clarity and structure*
to the existing laundry workflow.
